# Video Social Platform

A full-stack web application where users can upload videos, post tweets, create playlists, and interact with other users.

## Tech Stack
Frontend: React + Vite  
Backend: Node.js + Express  
Database: MongoDB  

## Features
- Authentication (JWT + Google OAuth)
- Video upload
- Tweets / posts
- Comments
- Playlists
- Subscriptions

## Run Locally

Backend
npm install
npm run dev

Frontend
npm install
npm run dev
